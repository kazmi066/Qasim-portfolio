# Qasim

Portfolio for a video editor, motion designer, and shorts editor. Cinematic type, pinned reel strip, and a quiet contact close.

## Stack

Next.js 16, Tailwind 4, shadcn, GSAP, Motion, Lenis, ShaderGradient, lucide-animated icons. Package manager is bun.

## Run

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
bun run build
bun run start
```

## Edit the person

Copy, contact, and reel metadata live in `src/content/site.ts` and `src/content/reels.ts`. Swap the Pexels stand-in videos for Qasim's masters when they are ready. Keep posters in `public/posters`.

## Design

Tokens, fluid type (Utopia), and BEM notes are in `DESIGN.md` and `src/app/globals.css`.
